How to test Payload Tampering

Section titled “How to test Payload Tampering”
  1. Select a preset (e.g., AI Agent Callback or Payment Event).
  2. Click ⚡ Tamper Body in the top-right toolbar. This modifies the HTTP POST body without re-signing the token.
  3. Observe how the receiver verification immediately flags a webhook.hash mismatch (HTTP 400 Bad Request), preventing tampered payloads or injected prompts from reaching your application.
  4. Click ↻ Re-sign Token to recompute webhook.hash and generate a fresh valid signature.
